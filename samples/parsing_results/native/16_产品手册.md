# 数据平台产品手册

本手册适用于数据平台 2.3 版本，面向系统管理员和数据分析师。阅读前请确认已获得管理员权限。更新日志见官方更新日志。

# 1 安装部署

## 1.1 环境要求

部署前需要准备以下环境：

操作系统：Ubuntu 22.04 或 CentOS 8

内存不少于 16 GB

生产环境建议 32 GB

数据库：PostgreSQL 14 及以上

## 1.2 安装步骤

下载安装包并校验 SHA-256

解压后执行安装脚本：

tar -xzf dataplat-2.3.tar.gz
cd dataplat && sudo ./install.sh --prefix /opt/dataplat

访问 http://<服务器IP>:8080 完成初始化

### 1.2.1 常见安装问题

若提示端口被占用，请修改 config.yaml 中的 server.port。
