### Algorithm 1  Reciprocal Rank Fusion

Input: ranked lists L1..Lm, weights w, constant k 1: for each document d in union(L1..Lm) do 2:     s(d) <- sum_i w_i / (k + rank_i(d)) 3: end for 4: return documents sorted by s(d) descending
